## What is package.json ?
- Package.json file is a configuration
- versions and configuration related information is stored as dependencies inside package.json file of the related project.
- It is installed through the command: 
`npm install <package name>`

## What is package-lock.json ?
- Package-lock.json locks the exact version of packages being used in the project.

## Difference between package.json and package-lock.json
|package.json|package-lock.json|
|------------|-----------------|
|generic version of packages|specific or exact version of packages|
|Manually created/edited by developers (via `npm init`)|Automatically generated by `npm`|
|High-level metadata: scripts, project name, author, dependencies.|Detailed info: exact versions, sub-dependencies, download URLs, and integrity hashes.|

## What are node_modules ?
- node_modules are independent, reusable blocks of code. 
- encapsulate specific functionality. 
- allows us to organize our application into manageable components.

## What is dist folder in React ?
- dist folder contains production-ready versions of our applications
- This will create a faster development version of our project and serves it on the server.
- To generate dist folder we use command: 
`npx parcel build index.html`

## What is a Transitive Dependencies ?
- The dependencies dependent on another dependencies are known as Transitive Dependencies

## What are Scripts inside package.json ?
- scripts are a collection of custom commands used to automate repetitive development tasks. 

## What is JSX in React ?
- JSX is a JavaScript XML
- It is a syntax extension for JavaScript used in React.
- It describe what the user interface should look like.
- It allows us to write HTML-like markup directly inside our JavaScript files. 
- Makes our code more readable and easier to maintain.

## What is Parcel ?
- Parcel is a "zero-configuration" web application bundler.
- It packages the code and optimizes the file which web browser can run and understand.

## What is a Bundler ?
- Bundlers are packages. If we want to use a package in our code, we have to use a package manager.

## What is Babel ?
- Babel is a JavaScript compiler (or transpiler) that translates modern code into a format browsers can actually understand.
- It acts as a bridge, allowing you to use cutting-edge features and specific React syntax without worrying about older browsers crashing.

## ES6
- ES6 (ECMAScript 2015) is a major update to JavaScript that introduced modern syntax and features, fundamentally changing how code is written. 
- It enables cleaner, more efficient code through block scoping, modularity, and simplified asynchronous handling.

## ReactElement in React
- ReactElement is a plain JavaScript object.
- It is the smallest building block of a React application and serves as a lightweight, virtual representation of a DOM node or a component.

## What are React Components ?
- React components are the fundamental building blocks of a React application.
- They are independent, reusable pieces of code
- Their types are:
1. Functional Components
2. Class Components

## What are React Functional Components?
- React functional components are the modern standard for building user interfaces in React. 
- They are plain JavaScript functions that accept data (known as "props") and return JSX (JavaScript XML)
- For e.g. :
``` js
function Welcome(props) { 
    return <h1>Hello,{props.name}</h1>; 
}
```    

## What are React Class Components ?
- React class components are ES6 classes that extend the built-in React.Component class to create reusable UI units.
- Before the introduction of Hooks in React 16.8, they were the primary way to manage state and complex logic.

## What are arrow functions in JavaScript ?
- Arrow provide a more concise syntax for writing function expressions in JavaScript. 
- They are particularly useful for simple one-line actions and are widely used in modern development for cleaner, more readable code.
- Basic syntax for it : ` const add = (a, b) => { return a + b; }; `
