## What is package.json ??
- Package.json file is a configuration
- versions and configuration related information is stored as dependencies inside package.json file of the related project.
- It is installed through the command: 
`npm install <package name>`

## What is package-lock.json ??
- Package-lock.json locks the exact version of packages being used in the project.

## Difference between package.json and package-lock.json
|package.json|package-lock.json|
|------------|-----------------|
|generic version of packages|specific or exact version of packages|
|Manually created/edited by developers (via `npm init`)|Automatically generated by `npm`|
|High-level metadata: scripts, project name, author, dependencies.|Detailed info: exact versions, sub-dependencies, download URLs, and integrity hashes.|

## What are node_modules ??
- node_modules are independent, reusable blocks of code. 
- encapsulate specific functionality. 
- allows us to organize our application into manageable components.

## What is dist folder in React ??
- dist folder contains production-ready versions of our applications
- This will create a faster development version of our project and serves it on the server.
- To generate dist folder we use command: 
`npx parcel build index.html`

## What is a Transitive Dependencies ??
- The dependencies dependent on another dependencies are known as Transitive Dependencies
